# Security Log Analyzer

A Python-based Security Log Analyzer that parses log files, detects failed login attempts, and identifies potential brute-force attacks.

## Features

- Read log files
- Parse log entries
- Extract usernames
- Extract IP addresses
- Count INFO, ERROR and WARNING logs
- Detect failed login attempts
- Detect possible brute-force attacks

## Technologies Used

- Python 3
- Dictionaries
- Functions
- File Handling
- Exception Handling
